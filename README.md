# Arabic-Legal-AI-Assistant

## Features
- Arabic legal document understanding
- Semantic document retrieval
- Context augmentation
- LLM-based answer generation
- Source/context-aware responses

## System Architecture
PDFs/Documents
      ↓
Text Extraction
      ↓
Chunking
      ↓
Embeddings
      ↓
Vector Database
      ↓
User Question
      ↓
Query Embedding
      ↓
Retrieval
      ↓
Context Augmentation
      ↓
LLM Generation
      ↓
Arabic Legal Answer
